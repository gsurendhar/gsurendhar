I don’t just deploy applications — I build reliable, secure, and scalable cloud environments that help engineering teams deliver faster with confidence.

I’m a DevOps & AWS Cloud Engineer around 4 years of hands-on experience in cloud infrastructure, CI/CD automation, Kubernetes, DevSecOps, and Infrastructure as Code. I enjoy solving infrastructure challenges, automating repetitive processes, and building efficient deployment workflows using AWS, Terraform, Docker, Kubernetes, Jenkins, GitHub Actions, and Helm.

Over the years, I’ve designed reusable CI/CD frameworks adopted across multiple projects, implemented DevSecOps quality gates that reduced pre-release vulnerabilities by nearly 40%, optimized Docker build efficiency, and supported zero-downtime Kubernetes upgrades and production deployments on Amazon EKS. I’ve also worked extensively with monitoring and observability tools like Prometheus, Grafana, and ELK Stack to improve incident visibility and troubleshooting efficiency.

Beyond engineering, I enjoy simplifying technical concepts and sharing practical knowledge with the community through blogs and LinkedIn posts focused on AWS, Kubernetes, Linux, networking, and DevOps best practices.

For me, DevOps is more than automation — it’s about collaboration, ownership, continuous improvement, and building systems that are scalable, reliable, and easy to maintain.

Currently, I’m looking for DevOps Engineer opportunities where I can contribute to cloud automation, Kubernetes operations, CI/CD modernization, and scalable AWS infrastructure projects while continuing to grow as a cloud and DevOps professional.
